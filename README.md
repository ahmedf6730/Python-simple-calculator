# Python Simple Calculator

A simple calculator built with Python as my first personal programming project.

## About the Project
This project is a command-line calculator developed to practice Python programming fundamentals.

## Features - Version 1.0
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User input through the terminal

## How to Run
1. Install Python 3.
2. Download the project files.
3. Open a terminal in the project folder.
4. Run the following command:

python Simple_calculator_version_1.py

## Known Limitations
- Invalid numeric inputs are not yet handled.
- Division by zero can cause an error.
- Unsupported operators are not properly validated.
